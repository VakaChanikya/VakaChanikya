## 👨‍💻 About Me

Cloud Network Engineer with **nearly 4 years of experience** designing, building, and supporting enterprise, hybrid, and AWS cloud networks. I specialize in AWS VPC, Transit Gateway, Direct Connect, and Site-to-Site VPN, backed by a deep Cisco routing and switching foundation (BGP, OSPF, EIGRP, MPLS, SD-WAN). I secure these environments with Palo Alto and FortiGate firewalls, and I use Python, Ansible, and Terraform to automate repetitive network operations at scale.

- 🔭 **Targeting:** Cloud Network Engineer and Cloud Engineer roles
- 📍 **Based in:** Nashville, Tennessee
- 🎓 **Education:** M.S. in Information Technology, Lindsey Wilson University · B.E. in Electronics & Communication Engineering
- 🌱 **Currently learning:** CCNP and AWS Advanced Networking
- 🤝 **Open to:** open-source collaboration and mentoring

### ☁️ AWS Hybrid Cloud Network Migration
Designed and executed the migration of a **200-device on-premises Cisco network** to an AWS hybrid architecture for a mid-size manufacturing company, completing the cutover with **zero unplanned downtime**.

- Built a **Transit Gateway hub-and-spoke** topology connecting **6 VPCs across 2 AWS regions**, with automated BGP failover to on-premises backup links
- Codified the infrastructure in **Terraform**, cutting provisioning time from **3 days to under 5 hours**
- **Tech stack:** `AWS VPC` `Transit Gateway` `IPSec VPN` `BGP` `Terraform` `Cisco IOS`

### 🤖 Network Automation & Monitoring Platform
Developed Python and Ansible automation for **VLAN provisioning, firewall rule updates, and daily configuration backups** across **80+ Cisco and FortiGate devices**.

- Added automated compliance checks against baseline templates, **preventing 5 major misconfigurations** from reaching production
- Reduced weekly manual network administration from **20 hours to under 3**, and the solution became standard practice across the network operations team
- **Tech stack:** `Python` `Ansible` `Netmiko` `SolarWinds` `Cisco IOS` `FortiGate`
